# flex-container-html2pdf-node changelog

## 1.0.0 (2026-11-13)

### Features

- Node.js 24 and TypeScript Azure Functions Flex Consumption container.
- Bounded HTML-to-PDF rendering with Puppeteer Core and OS-installed Chromium.
- Azure Developer CLI deployment with Bicep and Azure Container Registry Tasks.
- Deterministic image tags, immutable digest deployment, and scoped read-only
  registry credentials.
- Official floating `aka.ms` reference for the latest platform-independent
  Node.js worker.
- Cross-platform deployment and endpoint verification scripts.
